# FinSocratic｜FOF 经理跟踪与证据审计

本项目现在以 **React + Mantine + FastAPI + SQLite** 工作台为主入口。聚焦 FOF 经理研究：公开数据接入、净值诊断、报告检索、量化陈述核验、跨期配置跟踪、追问待办和报告导出。首页为 DeepSeek 驱动的 AI 研究会话：模型制定调查计划、选择工具、根据第一轮证据补查，再生成带证据编号的回答。支持连续追问与D盘持久化，未进行模型训练。

## 立即运行

双击 `启动应用.bat`，打开 http://127.0.0.1:8501 。源码包包含已构建的 `frontend/dist`，通常无需 Node.js；只有修改前端或缺少 dist 时才需 Node.js 20.19+ / 22.12+、运行 `npm ci` 与 `npm run build`。

建议 Python 3.11 / 3.12。脚本优先使用 D:\FinSocratic-ResearchAgent 存放环境、缓存和 SQLite；没有 D 盘时使用 LOCALAPPDATA。可用 FINSOCRATIC_HOME 和 FINSOCRATIC_PYTHON 覆盖默认值。

手动启动：安装 requirements.txt 后运行 `python -m finsocratic.api`。旧版 Streamlit 保留在 app.py，可另用 `python -m streamlit run app.py --server.port 8502`。

## 建议演示路线（3–5 分钟）

1. 总览 → 运行演示：查看合成案例的原文陈述、计算证据与跨期变化。
2. 数据导入 → 搜索 005215 → 接入研究：取得真实日频历史；点击“接入原始季报”读取管理人官网 2025Q2 历史披露。
3. 基金比较：选择同类型数据中的至少两只基金，按共同观测日期重算；可指定起止日期。经理跟踪可查看风险路径并导出单基金研究档案。
4. 研究副驾：选择真实基金，询问“分析该基金的风险和回撤”；查看执行工具与引用。再问报告相关问题，查看来源页码。
5. 尽调审计 → 计算与口径 → 导出 Markdown / JSON；研究待办记录跟进进度和处理备注。经理档案发起尽调会保留当前基金，参考季报也可选作现期输入；资料详情支持按关键词与页码查找。

## 专项研究能力

- 每条陈述区分原文、独立计算、证据边界与追问，材料相似不等于事实相符。
- 明确 ISO 日期区间或年度的量化陈述按区间复算；缺少边界观测则保留不确定性。复杂相对期间仍需研究员明确日期。
- PDF 表格自动抽取可能失去行列关系，自动核验不直接判定相符或矛盾；请核对原页后录入明确陈述。
- 两期持仓权重变化、净值滚动窗口、回撤恢复以及同起止收益区间相关性。
- 相对基准 Beta、Alpha、跟踪误差、信息比率和上下行捕获；这些是历史统计关系，不是策略收益贡献的因果证明。
- 本地持久化材料、审计与待办；公开数据保留源地址、抓取时间、SHA-256 和缓存状态。

## 数据与边界

内置三只 FOF、经理纪要及基准均为合成演示，明确标注。真实基金按 CN-代码独立入库。东方财富是销售平台数据源；净值研究指数用其报告的日涨跌幅逐期连乘，累计净值仅供参考，不冒充经过独立核对的复权净值。原始披露案例来自南方基金官网，报告期为 2025Q2，不称作最新报告。

没有取得的底层持仓、经理履历、交易、合同及完整费用保留缺口。美国 Fama-French 因子与沪深300自动研究上下文仅允许显式实验开关启用，默认审计不自动把它们当作中国FOF正式基准。应用为本机单用户研究工具，未提供生产级身份验证、权限隔离或多租户部署。

## 交付与复现

`FinSocratic_课程作业_源码.zip` 包含 Python、React 源码、已构建前端、依赖、方法说明和合成报告。真实下载缓存及用户数据库不进入源码包；接收者可从数据页重新下载。`python scripts/build_demo.py` 更新演示报告；`python scripts/package_submission.py` 重新打包。课堂实际操作视频需另行录制。

许可证与复用说明见 OPEN_SOURCE.md、THIRD_PARTY_COMPONENTS.md 和 frontend/NOTICE.md；公开数据来源与口径见 PUBLIC_DATA.md。


## AI 研究会话（本轮主线）

打开应用默认进入 AI 研究，选择基金，提出具体问题。模型最多先选择3项工具，并可补查1次报告；工具包含原始披露检索、收益回撤复算与持仓快照检查。页面的调查过程来自真实执行事件，不是预写的进度动画。回答提供证据编号，可展开查看报告页码与计算输入；引用不存在的编号时不会交付该回答。

会话保存于 FINSOCRATIC_HOME/data/workspaces/default/research_conversations.sqlite3，默认D盘。点击历史研究即可继续追问，保留最近4轮对话作为研究上下文。既有回答不是新的事实证据。问题与选中基金所需证据会发送到配置的DeepSeek服务；密钥仅从服务端环境或本机.env读取，不进入浏览器、源码包或会话。

API：GET /api/research/bootstrap，POST /api/research/ask，GET /api/research/sessions/{id}。异步研究允许前端显示真实进度；失败时明确显示失败原因，不冒充完成。

验证范围：生产前端构建、真实DeepSeek调用、原始年报检索、净值复算、引用存在性检查及连续追问。引用可定位不等于模型论断已逐项核实；财务表格关系与定性推断仍需研究员复核。
