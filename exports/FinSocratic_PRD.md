## 1. 概述

FinSocratic 是一个面向中国公募 FOF（基金中基金）的**基金经理证据尽调工作台**。它把「研究一只基金、核验一个投资论断」这一反复出现的研究动作，从「把资料丢给通用大模型、再人工核对计算」升级为一条**可复现、可追溯、可持续更新判断**的 Agent 工作流。

一句话定位：**它替研究员维护证据与更新判断，而不是只产出文字。**

---

## 2. 问题定义

FOF 研究中的真实痛点：

1. **资料分散**：净值来自销售平台、持仓来自定期报告 PDF、经理任职来自公告，口径与披露范围不一致。
2. **重复计算**：收益、回撤、同类超额收益每次都要重新算，方法不固定、结果不可复现。
3. **结论不可追溯**：一篇报告里的关键数字，很难回到「哪份原文、哪次计算」。
4. **跨期判断难延续**：新一季报告出来后，不知道上一版结论里哪些被支持、哪些被削弱、哪些没变。

### 核心对比：与「直接把文件交给 AI」的区别

| 研究动作 | 直接把文件交给通用 AI | FinSocratic 的差异 |
| --- | --- | --- |
| 准备数据 | 用户整理、上传、说明日期与口径 | 自动关联基金、报告期、净值与持仓 |
| 复算数字 | 每次重新要求计算 | 固定方法、相同输入可复现、保留口径 |
| 横向比较 | 用户另找同类资料 | 自动构造可检查的同类集合 |
| 找矛盾 | 高度依赖提示词 | 自动核对报告陈述、计算结果与披露范围 |
| 延续研究 | 依赖对话历史 | 保存假设、结论、证据及未解决问题 |
| 更新判断 | 再问一次，自己比答案 | 明确指出「新证据改变了什么判断、为什么」 |

## 3. 目标用户与场景

- **用户**：FOF 初筛与尽调研究人员；本课程场景下为评审老师演示真实研究能力。
- **主任务**：对一只 FOF 的「相对收益优势是否持续、现有材料能否支持经理能力」进行证据尽调，并在新增资料后更新判断。
- **次任务**：跨基金同区间比较、证据缺口识别、研究档案导出与复现。

---

## 4. 核心用户流程

**单次尽调闭环**

```
选择基金 → 委派研究 → 读取净值/持仓/模型/报告 → 查缺补证
→ 生成结论与反证 → 辅助核验 → 保存假设与输入快照 → 导出研究档案
```

**持续研究闭环**

```
恢复会话 → 上传新增材料（D 盘归档） → 优先检索新增材料
→ 比较输入指纹 → 记录「支持 / 削弱 / 未改变」的判断变化
```

## 5. 功能需求与验收标准

| 模块 | 行为 | 验收条件 |
| --- | --- | --- |
| 任务研究 | 完整尽调自动覆盖净值、持仓、报告、模型四类工具 | 过程记录与实际调用一致；无证据不伪装成功 |
| 证据引用 | 每个论断关联工具证据编号 | 引用不存在的编号时阻止交付 |
| 研究记忆 | 保存假设、结论、支持证据、反证、补证动作 | 服务重启后可恢复 |
| 版本比较 | 比较净值、持仓、原文、档案、模型的输入指纹 | 相同输入标注「未变」；新资料优先检索 |
| 资料归档 | 按 SHA-256 保存原始文件 | 存于 D 盘，原件可下载 |
| 报告交付 | 输出 Markdown 与可打印 HTML | 带历史版本与证据附件，重要数字可回到原文/计算 |
| 异常处理 | 超时、服务中断、缺资料时明确提示 | 不无限加载、不把失败显示成成功 |

## 6. 方法论与模型边界

系统刻意区分「统计信号」与「经理因果能力」，不在界面堆模型名称。

### 6.1 贝叶斯能力估计
- 估计对象：**同类 FOF 的相对季度超额收益均值**，而非「经理能力概率」。
- 输出：后验概率、95% 可信区间、逐季度后验变化、正收益季度占比、连续四季度稳定性、前后半段对比、先验敏感性。
- 明确标注替代解释（风格暴露、任职区间、持仓、风险因子）。

### 6.2 神经网络风险学习
- 目标：预测下一完整月份的年化波动；结构 `6 → 32 ReLU → 16 ReLU → 1`。
- 与「近期波动基线」「Ridge 线性模型」做时间外比较；未同时超过简单基线时，明确标记为**实验结果**，不参与经理能力判定。
- 优化后采用 3 网络集成 + 时间验证集早停 + 目标标准化，验证集选 50% 网络 + 50% 基线混合。

### 6.3 前瞻验证闭环
- 冻结模型权重、哈希、输入特征与预测，同月重复登记不覆盖。
- 与基线使用相同有效样本计算误差，缺失样本单列；当前独立验证成绩为空，最早在目标月结束后评估，**不提前宣称提升**。

## 7. 研究就绪度与证据缺口审计

每个训练代表产品生成一张「研究就绪度卡」，逐项检查：历史净值跨度、同类可比样本、时间稳定性、来源链接与数据哈希、经理任职区间、底层持仓与风格证据、风险模型时间外验证。输出 A/B/C 分级，缺证据直接降级，避免用总分掩盖研究盲点。

---

## 8. 数据与隐私

- 新增下载、运行环境、缓存、原件与导出全部存于 **D 盘**，不占用 C 盘。
- 模型配置（如 DeepSeek API Key）留在本地环境文件，不随源码交付。
- 研究必要的问题与证据发送给配置的模型服务；本地入库不自动上传。

---

## 9. 技术架构

- **后端**：FastAPI + Uvicorn + SQLite（WAL），pandas / NumPy / SciPy / scikit-learn。
- **前端**：React + Vite + TypeScript + Mantine，由 FastAPI 兜底提供静态资源。
- **数据目录**：`FINSOCRATIC_HOME = D:\FinSocratic-ResearchAgent`。
- **开源组件**：复用 Mantine、Recharts、react-markdown、Vite 等（许可证见 `THIRD_PARTY_COMPONENTS.md`）。
- **当前数据快照**：约 1,100 只基金、约 93 万条净值记录（持续扩充中）。

---

## 10. 非目标与范围边界

本期不包含：全市场完整任职与持仓覆盖、任意扫描件 OCR、多用户权限、交易执行、实时监控、层级贝叶斯 / 贝叶斯神经网络 / 大规模参数搜索。

---

## 11. 评价与演示

- 用相同材料对比「通用 AI」与本系统：数字可追溯、口径说明、反证、版本延续、人工步骤数量，不预设文字质量胜出。
- 演示顺序：委派任务 → 查看真实工具过程 → 定位引用 → 添加历史季报 → 查看版本变化 → 导出。
- 外部模型不可用时，展示带明确时间的真实历史记录，不模拟实时完成。
